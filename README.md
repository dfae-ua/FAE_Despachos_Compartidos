# Despachos Compartidos — FAE

Reserva de puestos en los despachos compartidos del Departamento de Fundamentos del Análisis Económico (UA).

## Acceso

👉 **[Abrir la app](https://dfae-ua.github.io/FAE_Despachos_Compartidos/)**

**No se reserva el despacho entero**: cada reserva ocupa **un puesto**. Varias personas pueden reservar la misma franja mientras queden puestos libres; la app muestra en cada hora cuántos quedan (p. ej. `5/8 libres`).

## Cómo usarlo

1. **Entra** con tu cuenta de Google (`@gcloud.ua.es` o `@ua.es`).
2. **Reserva**: elige despacho → navega al día → indica hora de inicio y fin → Reservar. El formulario te dice cuántos puestos quedan libres en esa franja.
3. **Cancela**: solo puedes cancelar tus propias reservas. El administrador puede cancelar cualquiera.

Reglas: una persona no puede tener dos reservas solapadas en el mismo despacho. Cuando una franja está completa aparece marcada como "Completo".
